- 0-putchar.c: prints "_putchar" followed by new line using _putchar function.
- main.h: header file with prototype of _putchar function.

- 1-alphabet.c: prints alphabet in lowercase followed by new line using print_alphabet function.
- main.h: header file with prototypes of _putchar and print_alphabet functions.

- 2-print_alphabet_x10.c: prints alphabet in lowercase 10 times, each followed by new line, using print_alphabet_x10 function.
- main.h: header file with prototypes of _putchar, print_alphabet and print_alphabet_x10 functions.

- 3-islower.c: checks for lowercase character using _islower function.
- main.h: header file with prototypes of _putchar, print_alphabet, print_alphabet_x10 and _islower functions.

- 4-isalpha.c: checks for alphabetic character using _isalpha function.
- main.h: header file with prototypes of _putchar, print_alphabet, print_alphabet_x10, _islower and _isalpha functions.

- 5-sign.c: prints sign of a number using print_sign function.
- main.h: header file with prototypes of _putchar,... and print_sign functions.
