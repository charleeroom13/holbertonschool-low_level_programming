# C - Pointers, arrays and strings

- 0-reset_to_98.c: function that sets value pointed to by an int pointer to 98.
- main.h: header file with prototypes of _putchar and reset_to_98 functions.

- 1-swap.c: function that swaps values of two integers.
- main.h: header file with prototypes of _putchar,... and swap_int functions.

- 2-strlen.c: function that returns length of a string.
- main.h: header file with prototypes of _putchar,... and _strlen functions.

- 3-puts.c: function that prints string followed by new line to stdout.
- main.h: header file with prototypes of _putchar,... and _puts functions.

- 4-print_rev.c: function that prints string in reverse followed by new line.
- main.h: header file with prototypes of _putchar,... and print_rev functions.

- 5-rev_string.c: function that reverses a string.
- main.h: header file with prototypes of _putchar,... and rev_string functions.

- 6-puts2.c: function that prints every other character of string followed by new line.
- main.h: header file with prototypes of _putchar,... and puts2 functions.

- 7-puts_half.c: function that prints second half of string followed by new line.
- main.h: header file with prototypes of _putchar,... and puts_half functions.

- 8-print_array.c: function that prints n elements of an array of integers.
- main.h: header file with prototypes of _putchar,... and print_array functions.

- 9-strcpy.c: function that copies string pointed to by src to buffer pointed to by dest.
- main.h: header file with prototypes of _putchar,... and _strcpy functions.

- 100-atoi.c: function that converts string to integer.
- main.h: header file with prototypes of _putchar,... and _atoi functions.
