# C - Hello, World

This project introduces basics of C: compiling with gcc, preprocessor, and printing text.

## Files

- 0-preprocessor: runs file in "$CFILE" through preprocessor and saves result in "c".
- 1-compiler: compiles file in "$CFILE" without linking and saves result in file with the same name and ".o" extension.
- 2-assembler: generates assembly code of file in "$CFILE" and saves result in file with the same name and ".s" extension.
- 3-name: compiles file in "$CFILE" and creates executable named "cisfun".
- 4-puts.c: prints exactly ""Programming is like building a multilingual puzzle" followed by new line, using puts.
